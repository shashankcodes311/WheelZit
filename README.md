# 🚲 WheelZit

Smart Bike Rental & Mobility Platform Prototype

## Overview

WheelZit is a startup-oriented mobility platform concept designed to simplify bike rentals and improve vehicle security using IoT-enabled technologies.

The project focuses on creating a seamless self-ride experience through app-based booking, GPS tracking, and smart security features.

## Key Features

- Smart Bike Booking
- GPS Tracking
- IoT-Based Vehicle Monitoring
- Remote Engine Lock/Unlock Concept
- User-Friendly Mobile Interface
- Startup Business Model Design

## Technologies

- Firebase
- IoT Concepts
- Embedded Systems
- Mobile App Prototyping
- Figma/UI Design
- AI Assisted Development
